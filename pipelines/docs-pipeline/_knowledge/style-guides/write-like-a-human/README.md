# Write Like a Human

Rules for making AI-edited prose read like human writing. Covers formatting tells, punctuation patterns, vocabulary, sentence structure, and tone.

## Style Guides

- **style-guide_write-like-a-human.md** - Comprehensive checklist of AI writing patterns to avoid: bold-label lists, em dash overuse, banned vocabulary, structural patterns, tone and voice rules, and an editing pass checklist

## When to use

Apply this guide whenever an AI agent is editing or generating prose content (documentation, guides, concept notes). The guide includes YAML frontmatter with an `instructions` field that tells agents how to use it.

## Research basis

Built from academic studies (Max Planck Institute, Northeastern, Johns Hopkins, University College Cork), community analysis (Reddit, Wikipedia's Signs of AI Writing guide), and model-specific pattern documentation across Claude, ChatGPT, Gemini, Grok, and DeepSeek.
