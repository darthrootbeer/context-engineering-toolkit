# Docs Platform Engineer, Copperline Example Co.

This is an invented job posting used to test a job assessment tool. Copperline Example Co. does not exist.

## About the team

Copperline makes writing tools for software teams. We are a remote company with about 60 people.

## What you will do

- Build and run the system that turns our documentation into a public help site.
- You will own the documentation system from the first week, with one other engineer to review your work.
- Keep docs-as-code habits healthy: all docs live in a Git repository as Markdown and are reviewed in pull requests.
- Our writers and engineers draft with AI assistants every day, and you will help decide which checks a human must still make.
- Documentation is part of the definition of done for every feature.
- You choose the tools and set the priorities for the docs system; your manager checks in once a week.

## What we are looking for

- 7+ years of experience in technical writing or documentation engineering.
- Experience generating API reference pages from an OpenAPI file.
- You can read Go code well enough to follow how our build tool works.
- The docs build is still run by hand before each release, and we want you to change that.

## Pay and benefits

- Base pay range for Region B: $100,000 to $104,000. Region A: $102,000 to $118,000.
- Unlimited paid time off, with a three-week minimum we ask everyone to take.
- A $3,000 yearly learning budget.
- Two team meetups a year.
